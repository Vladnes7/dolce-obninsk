# Dolce — правила для ИИ-агента (ChatGPT / Codex и другие)

Сайт кофейни-кондитерской **Dolce** (Обнинск). Сайт собран и работает. Задача агента: улучшать его небольшими аккуратными шагами, не ломая утверждённое.

## Где работать
- **Код сайта — только в `site/`.** Это Next.js 16 (App Router) + React 19 + Tailwind 4 + Motion.
- **Перед правкой кода прочитай `site/AGENTS.md`.** Next.js 16 отличается от привычного, документация лежит в `site/node_modules/next/dist/docs/` (после `npm ci`).
- `_материалы/` — исходники (фото, тексты, отзывы). Отсюда **берём**, но не правим без просьбы. На сайт материалы попадают через `site/public/img/` и `site/src/data/`.
- `server/` — выкладка на VPS. **Не трогать и не запускать** без явной команды владельца.

## Утверждённый дизайн (не менять без согласия владельца)
- Цвета: мятный `#86d3ca`, тёмно-мятный `#2c7a73` / `#23635d`, белый; текст `#1f3a37`, серого нет. Только через токены `globals.css`.
- Золотой и малиновый — **только** в блоке отзывов Яндекс Карт.
- Название — настоящий логотип (компонент `Wordmark`, картинка `public/img/brand/dolce-wordmark.png`), не шрифт.
- Шрифты: Playfair Display (заголовки), Onest (текст), Great Vibes (1–3 слова-подписи).
- Первый экран: `hero.jpg` (меренга) + две фото-арки. Бургер-меню мятное.
- **ВКонтакте не используем** (группу не ведут). Новости — из Telegram.
- Спокойные анимации, только `opacity`/`transform`. Всё работает с `prefers-reduced-motion`.
- Не возвращать View Transitions для перехода на блюдо: на iPhone тормозили.
- Без «шаблонного AI-дизайна»: случайных градиентов, лишних теней, безликих одинаковых карточек.

## Как работать
1. Перед правкой — короткий план (цель, файлы, 2–5 шагов, риски). Ждать согласия владельца.
2. Маленькие изменения, один смысл — один коммит. Сообщения коммитов по-русски.
3. Новые пакеты, выкладка на сервер, изменения в `server/` — только по явной просьбе.
4. Ключи и пароли не писать в код, файлы и коммиты.
5. Не выдумывать факты о кондитерской (цены, часы, адреса). Открытые вопросы: часы точки на Маркса, 89; минимальные суммы доставки; номер WhatsApp; сверка цен.

## Команды (из `site/`)
```bash
npm ci                      # зависимости
npx next dev -p 3030        # просмотр: http://localhost:3030
npx tsc --noEmit            # типы
npx eslint src              # линтер
rm -rf .next/cache && npx next build   # сборка (кэш чистить: однажды отдал старый CSS)
```
Перед сдачей проверь все три команды и вид на ширинах 360, 390, 768, 1024, 1440 px: ничего не вылезает за край, нет сдвига вбок, кнопки нажимаются, фото не выходят за рамки.

## Идеи для доработки (брать по одной, после согласия)
1. Блок «Новинки и напитки» из Telegram (`_материалы/соцсети/telegram/`).
2. Дописать тексты блюд, где есть только короткое описание (сверить с `услуги-и-цены.md`).
3. Сжать фото в `site/public/img/dish/` (~30 МБ) без потери качества.
4. SEO к запуску: разметка Product на страницах блюд, sitemap. Сейчас сайт закрыт от индексации — не открывать без владельца.
5. Доступность: контраст, порядок Tab, подписи к фото.

## Шрифты (проверено: все с кириллицей в Google Fonts)
- Рукописный акцент: **Great Vibes** (cyrillic есть). Ближайший к «Amoresa»: контрастная каллиграфия, использовать для 1-3 слов («Dolce», «с любовью», подписи к заголовкам). Не для абзацев.
- Заголовки: **Playfair Display** 500/600 + italic (контрастная антиква как «Cappuccino» с референса, красиво в разрежённых капсах как «RAMILLAS»). Подпись капсом: `letter-spacing: .28em`.
- Текст: **Onest** (остаётся).
- Unbounded убрать (слишком технично для этой стилистики).
Не подошли: Pinyon Script (нет кириллицы), Kaushan Script (нет кириллицы).

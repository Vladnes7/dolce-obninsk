# Сайты-референсы для Dolce (кондитерская-кофейня, Обнинск)

Режим РЕФЕРЕНС. Дата: 2026-10-24. Разбор в Chrome, 1440 px. Чужой код и тексты не копировались. Статусы: [изм] = измерено в браузере (computed style), [набл] = увидено глазами, [оцен] = оценка по скриншоту, не из кода.
Скриншоты: `скриншоты-референсов/` (имя = номер сайта, экран, ширина).

Общее ограничение: узкий экран проверить не удалось. Смена размера окна Chrome не меняет viewport, iframe 390 px сработал только на Desserto, Wix не перестраивается (мобильную раскладку отдаёт по UA). Поэтому «мобильная версия» ниже везде помечена как непроверенная, кроме Desserto.

- CTA: в hero два овала по центру внизу («PRODUCTS» залитая, «ORDER» контурная) + «ORDER NOW» текстом справа в шапке. Радиус 50%.
- Палитра [изм]: фон body #38302A (тёмный шоколад, лёгкий горизонтальный градиент), CTA-заливка #FFE592, текст на ней #38312A, текст белый. Крафт-панель серо-бежевая с зерном ~#A9A097 [оцен].
- Шрифты [изм]: заголовки «classico-urw» (серифный, тонкий, контраст), основной «urbane» (гротеск, веса 200 и 500), кнопки 16 px / 500. Источник подключения не проверялся.

## Что стоит взять (приёмы для кондитерской с предзаказом торта)

1. Форма предзаказа как у Yori's: пошаговые поля с выпадашками (размер, вкус, крем, начинка), в строке размера показан ориентир цены «от» и число порций; загрузка референс-фото; слот времени самовывоза; сроки (48 ч / неделя для сложных) выше формы; телефон рядом.
2. Постоянная кнопка заказа в шапке (Magnolia «Order ASAP»), шапка sticky; при первом заходе выбор «доставка / самовывоз» вместо перегруженного меню.
3. Карточки каталога как у Magnolia: одно фото на нейтральном фоне, название, цена «от», фильтры по размеру и вкусу; подборки по поводу и по бюджету («Подарки до N ₽»).
4. Цвет как навигация: каждая секция в своей цветной полосе на всю ширину (Magnolia) или смена фона секции при скролле заливкой снизу вверх (UND NY); без градиентного «шума».
5. Построчное раскрытие крупных заголовков маской и параллакс «плавающих» продуктов (Desserto) как единственная сильная анимация первого экрана; hover кнопок 0.2–0.5 s.
6. Доверие: лицо мастера/шефа с подписью в hero (Desserto), «своё производство» отдельным блоком (Брусника), награды/цифры («с 1996», «26 точек») на виду.
7. Акции строкой: бегущая строка и карусель баннеров с одной конкретной выгодой (Брусника) вместо длинных текстов.
8. Блок способов получения (самовывоз / доставка / заказ на событие) отдельной секцией перед футером (Magnolia «Delivery and Pick-Up Options»).

## Не проверено

- Мобильные версии всех сайтов, кроме Desserto (см. выше).
- UND NY: прокрутка живого сайта и «pastry scroll» на нём (эффект взят из видео Awwwards, 2024).
- Брусника: только архивная копия; ТортоФФ не открылся.
- Тайминги и easing scroll-анимаций (Desserto, UND NY, Magnolia): значения не измерялись, указаны наблюдения.
- Цвета с пометкой [оцен] взяты по скриншоту, точные hex не из CSS.

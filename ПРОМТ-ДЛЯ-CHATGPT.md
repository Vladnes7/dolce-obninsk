# Промт для ChatGPT: доработка сайта Dolce

**Репозиторий:** https://github.com/Vladnes7/dolce-obninsk (закрытый)

Перед первым запуском подключи GitHub в ChatGPT: «Настройки → Приложения (Connectors) → GitHub» → дай доступ к репозиторию `dolce-obninsk`. Для правок кода удобнее Codex (chatgpt.com/codex): выбери этот репозиторий как среду.

Скопируй в ChatGPT всё, что ниже линии.

---

Ты продолжаешь работу над сайтом кофейни-кондитерской **Dolce** (Обнинск). Репозиторий: **Vladnes7/dolce-obninsk**.

**Сначала прочитай в репозитории:**
1. `AGENTS.md` (в корне) — где работать, что где лежит, утверждённый дизайн, правила и команды. Это главный файл правил, следуй ему.
2. `site/AGENTS.md` — особенности Next.js 16.
3. `_материалы/редизайн-решения.md` — решения по дизайну (раздел «Итерация 2 — ДЕЙСТВУЕТ»).

**Коротко:**
- Код сайта — только в `site/` (Next.js 16 + Tailwind 4 + Motion).
- Фото, тексты меню, отзывы, посты Telegram — в `_материалы/`. Оттуда бери материалы для сайта.
- `server/` (выкладка на сервер) не трогай.
- Дизайн утверждён: мятный + тёмно-мятный + белый, золото и малина только в отзывах, ВКонтакте не используем.

**Как со мной работать:**
- Пиши по-русски, коротко и простыми словами.
- Перед любой правкой дай план: цель, файлы, 2–5 шагов, риски. Жди моего «делай».
- Каждое изменение — отдельным коммитом (или pull request) с понятным описанием по-русски.
- Перед сдачей прогони `npx tsc --noEmit`, `npx eslint src`, `npx next build` в папке `site/` и проверь вид на телефоне (360–430 px) и компьютере.
- Без моего разрешения: не ставь новые пакеты, не выкладывай на сервер, не открывай сайт для поисковиков.
- Отчёт после работы — до 6 пунктов: что изменено, как проверено, что осталось.

**Первая задача:** прочитай файлы выше и предложи 3 улучшения сайта на выбор (из списка «Идеи для доработки» в `AGENTS.md` или своих), с планом для каждого. Ничего не меняй, пока я не выберу.
